# MALTSEV DIGITAL

Сайт-портфолио независимого веб-разработчика: главная, работы, страница кейса, услуги и цены с
калькулятором, обо мне, вопросы, контакты с брифом, политика конфиденциальности и 404.

Стек: [Astro 7](https://astro.build), TypeScript, обычный CSS с токенами. Без фреймворков на клиенте:
весь интерактив — несколько маленьких скриптов. Сайт статический и работает на GitHub Pages.

## Запуск

Нужен Node.js 22.23 или новее.

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:4321. Другие команды:

| Команда | Что делает |
| --- | --- |
| `npm run build` | Production-сборка в папку `dist/` |
| `npm run preview` | Показывает собранный сайт локально |
| `npm run check` | Проверка типов TypeScript и Astro |
| `npm run check:launch` | Проверка, что все данные подтверждены (см. ниже) |
| `npm run dev:examples` | Dev-сервер с шаблоном проекта `_example.md` — чтобы посмотреть страницу кейса |

### Изображения

Положите PNG в `src/assets/gen/` с именем из `IMAGE_GENERATION_PROMPTS.md` — сайт подхватит его сам
и сожмёт в WebP при сборке. Если файла нет, показывается временная графика из `src/assets/placeholder/`
(для фона — нарисованная волна из `src/assets/bg/`).

### Шрифты

Unbounded (заголовки) и Onest (текст) подключены не целиком, а только нужными наборами символов:
латиница и кириллица, у Onest ещё расширенная латиница (там знак «₽») и символы (стрелки). Так первый
экран грузится быстрее. Файлы скопированы из пакетов `@fontsource-variable/*`; если понадобится другой
набор символов, скопируйте нужный `.woff2` из `node_modules/@fontsource-variable/<шрифт>/files/` в
`src/assets/fonts/` и добавьте `@font-face` в `src/styles/fonts.css`.

### Анимации

Первый экран собирается CSS-анимацией и не ждёт скриптов. Остальное (появление заголовков по
строкам, «прочитывание» манифеста, рост тарифов, параллакс, наклон стекла за курсором, магнитные
кнопки) делает GSAP, который загружается после страницы. Управление — атрибутами в разметке, список в
начале `src/scripts/motion.ts`. При «Уменьшить движение» в системе анимации отключаются, контент виден
сразу.

### Подтверждение данных

В `src/config/site.ts` у каждого непроверенного значения стоит `confirmed: false`. Пока такие значения
есть, на сайте видна плашка «Предварительная версия», контакты не превращаются в ссылки, а публикация
через GitHub Actions останавливается на шаге «Проверка перед запуском». Замените значение, поставьте
`confirmed: true` — и всё включится.

### Добавить проект в портфолио

1. Скопируйте `src/content/projects/_example.md` в новый файл, например `coffee-shop.md`. Имя файла
   станет адресом: `/portfolio/coffee-shop/`.
2. Положите картинки рядом (например, в `src/assets/projects/coffee-shop/`) и укажите пути в файле.
3. Заполните поля. Для демонстрационных работ поставьте `isConcept: true` — на сайте появится пометка
   «Концепт». В `results` пишите только реальные, проверяемые цифры.
4. Как только появится хотя бы один проект, полка на главной покажет его вместо пустого состояния, а
   блок «Этот сайт — первый кейс» скроется.

Файлы, имя которых начинается с `_`, не публикуются.

## Приём заявок (Formspree)

Формы отправляют данные в [Formspree](https://formspree.io) без перезагрузки страницы. «Заявка
отправлена» показывается только после ответа сервиса; при ошибке посетитель видит её текст и
контакты для связи напрямую. Бесплатный тариф Formspree — около 50 заявок в месяц.

1. Зарегистрируйтесь на formspree.io и создайте форму.
2. Скопируйте её ID — часть адреса `https://formspree.io/f/XXXXXXXX`.
3. Вставьте его в `src/config/site.ts` → `forms.formspreeId`.
4. В настройках формы на Formspree укажите домен сайта в списке разрешённых.

ID формы — не секрет, его можно хранить в публичном репозитории.

**Важно про закон о персональных данных.** Formspree хранит данные в США, а 152-ФЗ требует сначала
записывать данные граждан РФ в базы на территории России и уведомлять Роскомнадзор о трансграничной
передаче. Перед запуском проконсультируйтесь с юристом. Альтернатива — российский сервис форм
(например, Яндекс Формы) или свой сервер. Текст политики — черновик в `src/pages/privacy.astro`.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и отправьте туда код.
2. **Settings → Pages → Source: GitHub Actions.**
3. **Settings → Secrets and variables → Actions → Variables** — добавьте две переменные:
   - `SITE_URL` — `https://<логин>.github.io` (или ваш домен);
   - `BASE_PATH` — `/<имя-репозитория>` для адреса на github.io или `/` для своего домена.
4. Каждый пуш в `main` запускает `.github/workflows/deploy.yml`: проверка данных → сборка →
   публикация. Пулл-реквесты и другие ветки проверяет `check.yml` (без публикации).

### Свой домен

1. Создайте `public/CNAME` с одной строкой — доменом, например `maltsev.digital`.
2. У регистратора домена добавьте записи по инструкции GitHub:
   [Managing a custom domain](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site).
3. Поменяйте переменные: `SITE_URL=https://maltsev.digital`, `BASE_PATH=/`.
4. В **Settings → Pages** включите **Enforce HTTPS**.

### Обновить сайт после публикации

Измените файлы, сделайте коммит и пуш в `main` — через 1–2 минуты сайт обновится сам.

## Аналитика и cookies

Сейчас сайт не ставит cookies и не подключает аналитику, поэтому баннер согласия не нужен. Если
подключите Яндекс Метрику, понадобится баннер согласия на cookies и пункт о нём в политике.

## Как устроено

```
src/
  config/        бренд, контакты, цены, категории — всё, что меняется чаще кода
  data/          общие тексты: этапы, вопросы, направления
  content/       проекты портфолио (Markdown)
  components/    блоки страниц
  layouts/       общий каркас: шапка, подвал, SEO-метатеги
  pages/         страницы и служебные файлы (robots.txt, llms.txt)
  scripts/       клиентские скрипты: появление, формы, калькулятор, слои
  styles/        дизайн-система
docs/research.md исследование референсов
scripts/         проверка перед запуском
```

Скриншоты в `src/assets/case/` сняты с этого же сайта. После заметных изменений главной их стоит
переснять: открыть страницу на 1425×900 (и 376×814 для телефона) и сохранить снимок экрана.
