# Floating Mobile Header Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Реализовать выбранную владельцем плавающую мобильную шапку с прямой связью и нижним меню.

**Architecture:** `Header.astro` хранит разметку, адаптивные стили и существующее поведение десктопной
шапки. Контроллер `mobile-menu.ts` управляет нативным диалогом, блокировкой страницы и восстановлением
фокуса; `Icon.astro` добавляет только значки меню и закрытия.

**Tech Stack:** Astro, TypeScript, CSS, нативный HTML `dialog`; без новых зависимостей.

**Spec:** `docs/superpowers/specs/2026-11-15-mobile-header-design.md`

## Global Constraints

- Мобильный режим — ширина меньше 1024 px; десктопные навигация и CTA сохранены.
- Светлая тема, реальный `LogoMark`, ссылка «Написать», кнопки минимум 44×44 px, существующий `url()`.
- Нативный диалог, безопасные зоны, уменьшенное движение, восстановление фокуса и позиции страницы.
- По указанию владельца не запускать дополнительные локальные тесты и браузерные аудиты.

## Review Focus

- На ширине 320 px логотип, название, «Написать» и меню помещаются без наложений.
- На невысоком экране все ссылки доступны, список прокручивается внутри нижней панели.
- Кнопка, Escape и фон закрывают диалог и возвращают фокус к видимому элементу.
- Переход к десктопной ширине не оставляет открытый диалог или заблокированную страницу.
- Открытие и закрытие не сбрасывают прокрутку; навигация из меню не оставляет блокировку в истории.
